Concrete code changes (NearbyServices.jsx)

Step 1 — Add a new click guard ref
- At component top, near existing refs, keep deductedSellers but add a separate ref for click dedupe:
  - const clickedSellers = useRef(new Set());

Rationale:
- Prevent multiple deductions when the user clicks the same seller multiple times (within the same NearbyServices session/component instance).

Step 2 — Remove impression-based deductions
- In both places where deductSearchImpression(...) is currently called during rendering, delete the blocks:
  - In the marker render loop (MarkerClusterGroup -> nearby.map(...) when seller.isPremium):
    - remove the sellerId/serviceName deduction block entirely
  - In the right-side seller card render loop (nearby.map(...)):
    - remove the sellerId/serviceName deduction block entirely

After this, NearbyServices will only call isWalletSufficient() to decide visibility, but will not call deductSearchImpression() during render.

Step 3 — Add click handler that performs deduction
- Implement a handler inside NearbyServices.jsx, e.g.:
  - const handlePremiumSellerClick = (seller) => { ... }
- Logic inside handler:
  - if (!seller?.isPremium) return (no deduction)
  - if wallet is not sufficient (balance <= 0) then return or keep behavior consistent (your UI already hides when not sufficient, but defensive check is fine)
  - if clickedSellers.current has seller.id: return
  - else add seller.id to the set
  - call deductSearchImpression(seller.id, seller.service)
  - then trigger existing selection/navigation behavior:
    - setSelectedSellerId(seller.id) (right now onClick is used for selection)
    - marker click currently setsSelectedSellerId as well; decide whether you want deduction only from cards or also from map markers.

IMPORTANT interpretation from your prompt:
- “Only when a buyer actually clicks on a premium seller's service card”
- So apply the click handler to the right-side card click.
- Keep marker click unchanged (or optionally route it through the same handler if you consider marker click also a “click”; but to match your prompt precisely, restrict to the card click).

Step 4 — Wire handler to the card click only
- Replace current card onClick:
  - onClick={() => setSelectedSellerId(seller.id)}
- With:
  - onClick={() => handlePremiumSellerClick(seller)}

Step 5 — Keep visibility logic intact
- Do NOT change this part:
  - if (seller?.isPremium && !isWalletSufficient()) return null;
- This ensures ₹0 balance immediately hides premium sellers.
